# Application layer

Application layer показывает полный жизненный цикл приложения на созданной платформе.

Базовые учебные приложения:

- Flask;
- Django.

Треки:

- [Manual](manual/README.md);
- [Automation](automation/README.md).

Задача слоя — связать разработку, контейнеризацию, CI, registry, Kubernetes, database, logging, metrics, deployment и rollback в одну понятную цепочку.
