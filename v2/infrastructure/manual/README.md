# Infrastructure — Manual

Цель: студент должен понимать инфраструктуру до автоматизации.

План:

1. Proxmox и базовая топология.
2. Создание VM вручную.
3. Linux baseline.
4. Gateway / routing.
5. DNS / DHCP.
6. VPN.
7. Kubernetes bootstrap.
8. MetalLB / Ingress.
9. Ceph.
10. CSI.

На первом этапе этот трек использует проверенные материалы v1 через карту миграции. Копирование документов выполняется только после проверки ссылок, команд, версий и секретов.
