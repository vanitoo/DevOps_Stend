# Platform Engineering

Этот этап начинается после Manual и Automation.

Цель: разработчик использует платформу как продукт и не обязан знать детали каждого инфраструктурного шага.

Будущие темы:

- environment model: dev/stage/prod;
- application templates;
- self-service;
- golden paths;
- policy as code;
- secrets management;
- SSO;
- observability defaults;
- SLI/SLO;
- backup/DR;
- developer portal;
- lifecycle и upgrade strategy.

Критерий зрелости: новый сервис получает репозиторий, pipeline, deployment, DNS, secrets, observability и политики по стандартному шаблону, а не собирается вручную с нуля.
