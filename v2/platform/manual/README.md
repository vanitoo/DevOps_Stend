# Platform — Manual

На Manual-уровне студент самостоятельно устанавливает, настраивает и проверяет платформенные сервисы.

Каждый модуль v2 должен отвечать на пять вопросов:

1. Зачем нужен сервис?
2. От каких компонентов он зависит?
3. Как установить его руками?
4. Как проверить, что он действительно работает?
5. Как диагностировать типовые неисправности?

Текущие v1-инструкции используются как исходный материал, но не считаются автоматически актуальными для v2.
